## 二、P0 用例（必须有，5 个）

### UC-P0-01：工单列表查看

| 项目 | 内容 |
|------|------|
| **用例名称** | 工单列表查看 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服登录工作台，进入工单列表页面<br>2. 系统以表格形式展示工单列表，每行显示工单号、标题、状态、优先级、创建时间、负责人<br>3. 客服可上下滚动浏览工单数据<br>4. 列表支持分页或虚拟滚动加载更多数据 |
| **预期结果** | - 工单列表正确加载，表格列完整显示<br>- 滚动流畅，10 万条数据下帧率 ≥ 50fps<br>- 工单状态以语义色标签区分（待处理/处理中/已解决/已关闭）<br>- 列表数据为空时显示空状态提示 |
| **优先级** | P0 |
| **对应 E2E 测试** | Playwright：登录→进入列表→验证表格渲染→验证滚动加载→验证空状态 |

---

### UC-P0-02：工单筛选搜索

| 项目 | 内容 |
|------|------|
| **用例名称** | 工单筛选搜索 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服在工单列表页顶部使用筛选条件（状态、优先级、时间范围、负责人）<br>2. 在搜索框中输入关键词（工单号/标题/客户名）<br>3. 点击搜索或输入后自动触发筛选<br>4. 列表实时更新为符合条件的结果<br>5. 客服可清除筛选条件恢复全量列表 |
| **预期结果** | - 筛选条件组合生效，列表仅显示匹配工单<br>- 关键词搜索支持模糊匹配，结果高亮关键词<br>- 筛选/搜索后列表计数更新<br>- 清除筛选后恢复完整列表<br>- 筛选后滚动位置不丢失（虚拟滚动场景） |
| **优先级** | P0 |
| **对应 E2E 测试** | Playwright：选择状态筛选→输入关键词→验证结果过滤→清除筛选→验证恢复 |

---

### UC-P0-03：工单详情查看

| 项目 | 内容 |
|------|------|
| **用例名称** | 工单详情查看 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服在工单列表中点击某条工单<br>2. 系统打开工单详情页（侧边抽屉或独立页面）<br>3. 展示工单完整信息：工单号、标题、描述、客户信息、状态、优先级、创建时间、处理记录、内部备注<br>4. 客服可浏览处理时间线 |
| **预期结果** | - 工单详情正确加载，所有字段完整显示<br>- 处理时间线按时间倒序排列<br>- 长文本描述完整展示不截断<br>- 从详情返回列表时，列表的筛选条件和滚动位置保持不变<br>- 页面加载无布局偏移（CLS 达标） |
| **优先级** | P0 |
| **对应 E2E 测试** | Playwright：点击工单→验证详情字段→验证时间线→返回列表→验证状态保持 |

### UC-P0-04：工单状态流转

| 项目 | 内容 |
|------|------|
| **用例名称** | 工单状态流转（待处理→处理中→已解决→已关闭） |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服在工单详情页查看当前状态<br>2. 点击"开始处理"按钮，工单状态从"待处理"变为"处理中"<br>3. 处理完成后点击"标记已解决"，状态变为"已解决"<br>4. 确认无误后点击"关闭工单"，状态变为"已关闭"<br>5. 每次状态变更需可添加备注说明 |
| **预期结果** | - 状态按 待处理→处理中→已解决→已关闭 单向流转，不可逆向跳步<br>- 状态变更后按钮状态同步更新（已关闭的工单不可再操作）<br>- 每次变更记录到处理时间线，包含操作人、时间、备注<br>- 状态标签颜色随状态变化（语义色 Token）<br>- 状态变更后列表中对应工单的状态同步更新 |
| **优先级** | P0 |
| **对应 E2E 测试** | Playwright：打开工单→依次点击状态按钮→验证状态标签变化→验证时间线记录→验证已关闭工单不可操作 |

---

### UC-P0-05：实时消息通知

| 项目 | 内容 |
|------|------|
| **用例名称** | 实时消息通知 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服登录工作台后，WebSocket 自动连接<br>2. 当有新工单/客户消息时，系统实时推送通知<br>3. 页面右上角通知铃铛显示未读计数角标<br>4. 客服点击铃铛查看通知列表<br>5. 客服点击单条通知跳转至对应工单详情<br>6. 客服可标记通知为已读 |
| **预期结果** | - WebSocket 连接成功，心跳保活正常<br>- 新消息从接收到 UI 展示延迟 ≤ 100ms<br>- 未读计数角标实时更新，无需刷新页面<br>- 通知列表按时间倒序排列，未读项视觉区分<br>- 点击通知正确跳转至对应工单<br>- 标记已读后角标计数减少<br>- 网络断开后自动重连（指数退避），重连后同步离线消息<br>- 多标签页共享单连接，消息不重复消费 |
| **优先级** | P0 |
| **对应 E2E 测试** | Playwright：登录→模拟 WebSocket 推送→验证角标更新→点击通知→验证跳转→标记已读→模拟断网重连→验证离线消息同步 |

## 三、P1 用例（应该有，4 个）

### UC-P1-01：Dashboard 概览

| 项目 | 内容 |
|------|------|
| **用例名称** | Dashboard 统计概览 |
| **用户角色** | 付费企业客户（管理方）、客服用户（使用方） |
| **操作流程** | 1. 用户登录后进入 Dashboard 首页<br>2. 查看核心指标卡片：今日新增工单、待处理工单、已解决工单、平均响应时长<br>3. 查看工单趋势图表（近 7 天/30 天）<br>4. 查看工单状态分布饼图<br>5. 可按时间范围筛选统计数据 |
| **预期结果** | - 指标卡片数据准确，与后端统计一致<br>- 图表渲染正常，支持时间范围切换<br>- 数据加载时显示骨架屏，无布局偏移<br>- 管理员可查看全团队数据，客服仅查看个人数据（权限隔离） |
| **优先级** | P1 |
| **对应 E2E 测试** | Playwright：进入 Dashboard→验证指标卡片→切换时间范围→验证图表更新 |

### UC-P1-02：多租户主题切换

| 项目 | 内容 |
|------|------|
| **用例名称** | 多租户动态主题切换 |
| **用户角色** | 付费企业客户（管理方） |
| **操作流程** | 1. 管理员进入主题设置页面<br>2. 选择或自定义品牌主色、辅助色、圆角风格、间距密度<br>3. 实时预览主题效果<br>4. 保存主题配置<br>5. 该租户下所有客服用户的工作台立即应用新主题 |
| **预期结果** | - 主题切换通过 CSS 变量运行时生效，无需全局重新渲染<br>- 主题切换无 FOUC 闪烁（内联脚本提前注入变量）<br>- 主色、辅助色、圆角、间距等 Token 均正确更新<br>- 不同租户主题相互隔离，互不影响<br>- 刷新页面后主题保持（主题配置持久化） |
| **优先级** | P1 |
| **对应 E2E 测试** | Playwright：进入主题设置→更改主色→验证预览→保存→刷新页面→验证主题持久化→验证无 FOUC |

### UC-P1-03：国际化切换

| 项目 | 内容 |
|------|------|
| **用例名称** | 国际化语言切换 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服点击页面顶部的语言切换器<br>2. 从下拉菜单中选择目标语言（中文/英文/日文等）<br>3. 界面文案立即切换为目标语言<br>4. 日期格式、数字格式同步本地化<br>5. 切换语言后当前操作状态（如已打开的弹窗、表单输入内容）不丢失 |
| **预期结果** | - 界面所有文案切换为目标语言，无遗漏硬编码文案<br>- 日期格式按语言区域本地化（如中文 2026/8/18，英文 Aug 18, 2026）<br>- 数字格式按语言区域本地化<br>- 语言切换不丢失当前页面状态和表单草稿<br>- 语言偏好持久化，刷新后保持 |
| **优先级** | P1 |
| **对应 E2E 测试** | Playwright：切换语言→验证文案变化→验证日期格式→验证表单状态保持→刷新验证持久化 |

### UC-P1-04：响应式适配

| 项目 | 内容 |
|------|------|
| **用例名称** | 响应式布局适配 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服在桌面大屏（≥1280px）上使用工作台，查看完整布局<br>2. 客服切换到平板（768px–1024px），布局自动调整<br>3. 导航在小屏上折叠为汉堡菜单<br>4. 表格密度自适应调整，列数按需精简 |
| **预期结果** | - 大屏：侧边导航展开，表格显示全部列，布局宽松<br>- 平板：导航折叠为图标或汉堡菜单，表格精简次要列，密度适中<br>- 所有交互元素在触屏上可正常点击（最小点击区域 ≥44px）<br>- 无横向滚动条，内容不溢出<br>- 断点切换时无布局跳动 |
| **优先级** | P1 |
| **对应 E2E 测试** | Playwright：设置不同视口尺寸→验证导航折叠→验证表格列调整→验证无横向溢出 |

### UC-P2-03：虚拟滚动大数据性能

| 项目 | 内容 |
|------|------|
| **用例名称** | 10 万条工单虚拟滚动性能验证 |
| **用户角色** | 客服用户（使用方） |
| **操作流程** | 1. 客服打开一个包含 10 万条历史工单的大型客户工单列表<br>2. 快速滚动列表（拖动滚动条/滚轮）<br>3. 在滚动过程中使用筛选/搜索<br>4. 长时间停留并持续滚动（模拟 30 分钟使用） |
| **预期结果** | - 初始渲染仅加载视口内数据，DOM 节点数保持稳定（几十条）<br>- 快速滚动帧率 ≥ 50fps，无白屏闪烁<br>- 动态行高内容不截断，滚动位置不跳动<br>- 筛选/搜索后滚动位置正确恢复<br>- 长时间使用后内存占用稳定，无泄漏（事件监听正确清理） |
| **优先级** | P2 |
| **对应 E2E 测试** | Playwright：加载 10 万条数据→快速滚动→验证 DOM 节点数→验证帧率→筛选后验证滚动恢复→长时间操作后验证内存 |

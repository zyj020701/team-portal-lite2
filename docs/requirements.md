# Team Portal Lite 需求文档

> 本文档回答项目的四个核心问题（给谁用 / 解决啥 / 做成啥样 / 怎么衡量），并列出 10 个核心使用场景。

---

## 一、四问答案

### 1. 给谁用（Who）

Team Portal Lite 面向大型企业客服部门的 **B2B SaaS 工单管理系统前端**（"高级接单台"），主要用户群体包括：

- **一线客服人员**：日常接收、处理、回复工单，占用户 majority
- **客服主管/组长**：分配工单、监控团队工作量、处理升级工单
- **企业管理员**：配置租户主题、管理团队成员、查看数据报表
- **系统管理员（平台方）**：管理多租户、系统配置、权限分配

业务规模：支撑 **5000+** 付费企业客户、**100 万** 客服人员、**DAU 30 万**。

### 2. 解决啥（Why）

现有客服系统存在以下痛点：

1. **工单处理效率低**：列表加载慢、筛选不灵活、批量操作缺失，客服每日处理工单耗时长
2. **多租户品牌定制困难**：不同企业客户需要不同主题色和品牌风格，现有系统为每租户打包独立 CSS，维护成本高
3. **实时性差**：工单分配、状态变更依赖轮询，消息延迟可达数分钟，客服无法及时响应
4. **大数据量卡顿**：工单列表在万级数据量下出现明显卡顿，滚动掉帧、操作迟滞
5. **多端体验不一致**：管理后台、客服工作台、移动端各自为战，代码重复、体验割裂

### 3. 做成啥样（What）

构建一套基于 **Next.js 14 + RSC + App Router** 的 Monorepo 前端架构，核心功能包括：

- **多租户动态主题系统**：运行时 CSS 变量换肤，一套 CSS 支持所有租户，切换无闪烁
- **WebSocket 实时通知**：心跳保活、指数退避重连、消息队列批量更新、多标签页同步
- **大数据虚拟滚动列表**：10 万条数据流畅滚动（≥50fps），DOM 节点稳定在 20-30 个
- **工单列表页**：多维度筛选、搜索防抖、URL 状态同步、批量操作、键盘可访问
- **工单详情页**：状态机驱动流转、时间线、内部备注、实时通知推送
- **响应式适配 + 国际化**：桌面端/移动端适配，中英文多语言支持

### 4. 怎么衡量（How）

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| Lighthouse 性能分 | ≥ 96 | Lighthouse CI 自动检测 |
| TypeScript 严格模式 | 0 个 `any` | ESLint `no-explicit-any` + CI 阻断 |
| 测试覆盖率 | ≥ 75% | Vitest 覆盖率报告 |
| 虚拟滚动帧率 | ≥ 50fps（10 万条数据） | Chrome DevTools Performance 录制 |
| WebSocket 消息延迟 | ≤ 100ms（接收到 UI 展示） | Performance API 打点 |
| 列表首屏加载 | ≤ 2s | Lighthouse / 本地模拟 |

## 二、10 个核心使用场景

### P0（必须有）

1. **客服查看工单列表**
   - 客服登录后进入工单列表页，默认展示待处理工单，按创建时间倒序排列
   - 列表支持虚拟滚动，万级数据流畅滚动
   - 每行展示工单编号、标题、客户名称、优先级、状态、创建时间、处理人

2. **筛选与搜索工单**
   - 客服可通过状态（多选）、优先级、处理人筛选工单
   - 关键词搜索支持工单标题和客户名称模糊匹配，300ms 防抖
   - 筛选条件同步到 URL，刷新后保持，可分享链接

3. **工单状态流转**
   - 客服打开工单详情，根据状态机执行合法操作（待处理→处理中→已解决→已关闭）
   - 非法转换按钮禁用，提交时纯函数二次校验
   - 关闭工单需二次确认

4. **实时接收工单通知**
   - 客服收到新工单分配时，顶部铃铛实时显示未读计数
   - WebSocket 断连自动重连（指数退避），重连后同步离线消息
   - 多标签页登录时仅一个标签维持连接，状态同步

5. **多租户主题切换**
   - 不同企业客户登录后看到对应品牌主题色
   - 主题切换 ≤ 50ms，无白屏、无 FOUC 闪烁
   - 所有组件（Button/Input/Modal/Table）颜色、圆角跟随主题变化

### P1（应该有）

6. **批量操作工单**
   - 客服勾选多行工单后，可批量分配处理人或批量关闭
   - 批量关闭需二次确认，操作成功后列表实时刷新

7. **添加工单备注**
   - 客服在工单详情页添加内部备注，支持多行文本
   - 备注按时间倒序展示，提交后实时刷新

8. **工单排序**
   - 点击表头按创建时间升/降序排序
   - 点击优先级表头按优先级排序
   - 排序方向图标正确指示

### P2（可以有）

9. **返回列表状态保持**
   - 从工单详情返回列表时，筛选条件、搜索关键词、排序方式、滚动位置精确恢复
   - 数据通过 TanStack Query 缓存，不重复请求

10. **键盘可访问性**
    - 列表支持上下方向键导航，Enter 进入详情，Esc 返回
    - 所有交互控件可通过 Tab 聚焦，焦点环可见
    - 符合 WCAG 2.1 AA 标准
